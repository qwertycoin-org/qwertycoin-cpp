# Security policy

Security fixes target current `master` and its committed Qwertycoin Core
gitlink. Report vulnerabilities privately through GitHub's **Report a
vulnerability** form in this repository's Security tab; do not open a public
issue.

Include the exact bridge and Core revisions, build target, reproduction steps,
and impact. Never include wallet seeds, spend keys, wallet files, or production
credentials. Memory-safety, key-handling, serialization, ABI-boundary, and
funds-safety reports receive the highest priority.
